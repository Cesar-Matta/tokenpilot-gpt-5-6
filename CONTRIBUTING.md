# Contributing

Thanks for improving TokenPilot.

1. Open an issue for substantial policy or API changes before implementing them.
2. Keep routing changes explainable and add representative tests.
3. Update model prices only with a source URL and date.
4. Run `ruff check .`, `pytest`, `python scripts/validate_skill.py`, and `python scripts/public_release_check.py`.
5. Do not commit credentials, customer data, internal endpoints, or local paths.

By contributing, you agree that contributions are licensed under Apache-2.0.
